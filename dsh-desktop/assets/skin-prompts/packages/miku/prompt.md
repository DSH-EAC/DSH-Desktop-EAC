# 初音未来 · 电子歌姬皮肤

## 设计目标

为 DSH 客户端制作一套具有电子歌姬舞台感的完整皮肤。视觉应明确传达
初音未来主题，但不能牺牲聊天、会话导航、文件预览和设置页面的可读性。
皮肤只改变视觉和装饰，不重新设计业务流程。

## 视觉关键词

电子歌姬、蓝紫渐变、洋红点缀、01 编号、音乐波形、半透明玻璃、轻量舞台
灯光、清晰科技感。避免做成单一深蓝后台，也避免用高饱和颜色覆盖所有
内容区域。

## 色彩系统

- 主强调色使用亮蓝 `#2e9bff`，深色主题可提高到 `#58a9ff`。
- 辅助渐变依次使用深蓝、亮蓝、紫色和洋红，主要用于标题栏及少量强调面。
- 浅色主题以冷白、浅蓝和低透明玻璃为背景。
- 深色主题以近黑蓝、藏蓝和中低透明玻璃为背景。
- 成功、警告和错误状态保留绿、黄、红语义色，不能全部改成品牌蓝。
- 文本与背景必须保持清晰对比；正文区域不得使用洋红色大面积铺底。

## 字体与排版

- 中文优先使用 `PingFang SC`、`Microsoft YaHei`，英文和界面文字使用
  `Segoe UI` 作为后备。
- 代码区域使用 `JetBrains Mono`、`Cascadia Code` 或 `Consolas`。
- 正文保持正常字重；标题栏、状态徽标和 `01` 编号可以使用较高字重。
- 不通过缩小字体制造科技感，不改变客户端既有信息层级。

## 页面布局

- 保留客户端原有标题栏、侧边栏、会话区、输入区、预览区和设置区布局。
- 页面背景使用蓝色系径向光晕、冷色线性渐变和主题插画组成舞台背景。
- 内容面板采用半透明表面与轻度模糊，让背景可见但不能干扰正文。
- 侧边栏顶部可使用蓝、紫、洋红横向渐变，主体保持更安静的玻璃表面。
- 标题栏加入 `01` 编号或音乐符号，底部状态栏可使用低密度波形元素。
- 弹窗、菜单和设置面板使用更高不透明度，确保浮层边界清楚。

## 核心控件

- 输入框、文本域和选择器使用玻璃表面、蓝色细边框和清晰焦点环。
- 主按钮使用亮蓝渐变，悬停时提高亮度，按下时产生轻微内阴影。
- 普通按钮保持低对比表面，危险按钮继续使用红色语义。
- 圆角以 6 至 8 像素为主，不使用夸张胶囊形状。
- 菜单、弹窗、抽屉和设置卡片使用一致的玻璃层级与边框。
- 滚动条采用蓝色滑块；悬停和按下状态必须可见。
- 链接、选中区域、当前分支及焦点状态使用蓝色强调，不只依赖透明度变化。

## 明暗主题

- 浅色主题保持冷白底和浅蓝面板，正文使用深蓝灰文字。
- 深色主题使用近黑蓝底和藏蓝面板，正文使用浅蓝白文字。
- 两种主题拥有相同的信息层级和控件状态，不能只对浅色主题做完整设计。
- 主题切换后背景图、遮罩、边框、阴影和滚动条必须同步变化。

## 动画与交互

- 颜色、边框、阴影和透明度变化控制在约 120 毫秒。
- 背景装饰不得持续高速运动，不制造影响阅读的闪烁。
- 当系统启用 `prefers-reduced-motion: reduce` 时，关闭非必要动画和过渡。
- 悬停、按下、焦点、选中、禁用和危险状态都必须能相互区分。

## 业务与接口边界

- 保留 DSH 客户端现有 DOM 语义、事件、插件接口和业务行为。
- 不修改会话创建、消息发送、附件、文件预览、终端、Git 图、设置和窗口
  控制逻辑。
- 不因视觉需要隐藏不可替代的按钮、状态或错误提示。
- 皮肤作用域使用 `body[data-dsh-miku]`，避免样式泄漏到未启用皮肤的页面。
- 可覆盖既有 `--dsw-*` 与 AionUI 视觉变量，但不得改变变量所表达的业务语义。
- 不把随机构建 class 作为唯一选择器；使用稳定属性和语义选择器作为主路径。

## 可用素材

- 视觉元数据：`dsh-desktop/assets/skins/miku/skin.json`
- EAC 实现：`dsh-desktop/assets/skins/miku/lib/client.js`
- 浅色预览：`dsh-desktop/assets/skins/miku/preview/light.png`
- 深色预览：`dsh-desktop/assets/skins/miku/preview/dark.png`
- AIO 历史来源：提交 `89757fa4b10d789e7bec028102569deefdceafc9`
  下的 `assets/skins/miku/`

以预览图确认整体气质，以源代码确认细节。不要从压缩 CSS 的偶然选择器名称
推导新的业务结构。

## 验收标准

1. 首屏能够辨认出蓝紫电子歌姬主题，并出现 `01` 或音乐波形标识。
2. 标题栏、侧边栏、会话区、输入框、菜单、设置和预览区域视觉统一。
3. 浅色与深色主题均可正常阅读，文本、焦点和状态颜色清晰。
4. 输入、发送、导航、附件、预览、设置及窗口控制行为与换肤前一致。
5. 禁用、悬停、按下、焦点、错误和选中状态完整。
6. 减少动态效果设置生效。
7. 禁用该皮肤后，不残留 body 属性、内联背景或注入的装饰节点。
