# Windows XP (Luna) 皮肤

## 设计目标

复刻 Windows XP Luna 桌面体验：蓝色窗口条、绿色开始按钮、米色状态栏和
Bliss 蓝天草地背景。保留经典直角和立体边框，但适配现代高分辨率。

## 视觉关键词

Windows XP、Luna、Bliss、蓝色标题栏、绿色开始按钮、米色状态栏、
资源管理器、直角、立体边框。

## 色彩系统

主强调色使用 `#316ac5`，标题栏使用亮蓝渐变，开始按钮使用草绿色，状态栏
使用米色。深色主题使用近黑蓝，但保留 Luna 蓝作为结构识别色。

## 页面布局

窗口背景模拟 Bliss 天空与草地，应用主体像 XP 窗口置于桌面之上。顶部为
Luna 标题栏，底部为米色状态栏，侧边栏可借鉴资源管理器任务面板。

## 核心控件

全局以直角或极小圆角为主。按钮使用立体高光与深色下边框；输入框采用白底、
内凹边框。绿色开始按钮只能对应真实入口，不能制造无功能按钮。

## 明暗主题

浅色主题忠于经典 Luna 和 Bliss；深色主题采用夜间桌面与深色窗口表面，
仍保留蓝色标题栏和清楚的边框层级。

## 动画与交互

交互采用即时高光、按下和边框变化，不使用现代大幅缩放或弹性动画。
减少动态效果时关闭所有非必要过渡。

## 业务与接口边界

作用域限定在 `body[data-dsh-xp]`。不伪造系统托盘、开始菜单或窗口状态。
标题栏按钮必须调用真实窗口能力；皮肤不得修改会话、文件、输入和设置逻辑。

## 验收标准

1. Luna 标题栏、绿色开始按钮、米色状态栏和 Bliss 背景可辨认。
2. 直角控件、立体边框与现代可读性兼容。
3. 明暗主题及窗口控件行为正确。
4. 禁用后不残留背景、状态栏或装饰节点。
